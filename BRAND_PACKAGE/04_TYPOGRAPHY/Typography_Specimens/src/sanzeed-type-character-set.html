Character set

Every glyph the subsets carry.

The woff2 web subsets cover Latin, Latin Extended-A, general punctuation and the rupee sign; Inter and Inter Tight also carry the arrows (Fraunces does not — arrows in a serif line are set in Inter). The TTFs installed for desktop work carry the full character sets. Numerals are shown proportional, tabular and old-style.
