Rulesfrom typography-tokens.json
  • Fraunces is always weight 300 (Light); use opsz 144 above 48 px, 72 for 24–48 px, 36 below.
  • Headlines are sentence case and end with a full stop. The last word may be set in gold (.lit) or Mist (.dim) — never both in one composition.
  • Never letter-space Fraunces; never set it below 16 px / 9 pt.
  • Italic is reserved for pull quotes and the personal line.
