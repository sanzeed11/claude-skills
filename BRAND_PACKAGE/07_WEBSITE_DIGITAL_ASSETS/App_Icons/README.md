# App_Icons — iOS, Android, Windows, macOS and PWA icons

Built by `build_app_icons.py` from the logo system's SVGs (`02_LOGO_SYSTEM/SVG/sanzeed-symbol-tile-square--dark.svg`, `sanzeed-symbol-tile--dark.svg`, `sanzeed-symbol--full-colour-dark.svg`) with cairosvg. The tile is Night `#0D0D0F`, the S Gallery White, the point Lamp Gold. Run `python3 build_app_icons.py` from this folder to rebuild everything, including `app-icons-preview.png`.

## Files and the tags that use them

| File | Spec | Tag / where it goes |
|---|---|---|
| `iOS/ios-icon-180.png` | 180×180, square, no alpha (iOS applies its own mask) | `<link rel="apple-touch-icon" sizes="180x180" href="/ios-icon-180.png">` — iPhone home screen |
| `iOS/ios-icon-167.png` | 167×167 | `<link rel="apple-touch-icon" sizes="167x167" href="/ios-icon-167.png">` — iPad Pro |
| `iOS/ios-icon-152.png` | 152×152 | `<link rel="apple-touch-icon" sizes="152x152" href="/ios-icon-152.png">` — iPad |
| `iOS/ios-icon-120.png` | 120×120 | `<link rel="apple-touch-icon" sizes="120x120" href="/ios-icon-120.png">` — iPhone @2× |
| `iOS/ios-icon-1024.png`, `iOS/ios-app-store-1024.png` | 1024×1024, RGB, no alpha, no rounded corners | App Store Connect / Xcode asset catalogue (“App Store iOS 1024pt”) |
| `Android/android-icon-48.png` … `-512.png` | 48, 72, 96, 144, 192, 256, 384, 512 — rounded tile with transparent corners | legacy launcher icons `mipmap-mdpi … xxxhdpi` (48 → 192) and the Play Store listing (512) |
| `Android/android-maskable-512.png` | 512×512, full-bleed Night, symbol inside the central 60 % (20 % safe padding on every side) | adaptive / maskable icon; the launcher may crop to a circle, squircle or rounded square |
| `Windows/mstile-70x70.png`, `-150x150.png`, `-310x310.png`, `-310x150.png` | transparent PNG, symbol at 50 % of the short side; tile colour comes from `browserconfig.xml` | `<meta name="msapplication-config" content="/browserconfig.xml">` and `<meta name="msapplication-TileColor" content="#0D0D0F">` |
| `Windows/browserconfig.xml` | the four tiles + `<TileColor>#0D0D0F</TileColor>` | serve from the site root |
| `macOS/safari-pinned-tab.svg` | single-colour symbol (black), Safari recolours it | `<link rel="mask-icon" href="/safari-pinned-tab.svg" color="#0D0D0F">` |
| `PWA/pwa-icon-192.png`, `PWA/pwa-icon-512.png` | rounded tile, transparent corners | manifest `icons` (`purpose: any`) |
| `PWA/pwa-maskable-512.png` | same construction as the Android maskable | manifest `icons` with `"purpose": "maskable"` |
| `PWA/manifest.webmanifest` | name, short_name, description, icons, `theme_color` and `background_color` #0D0D0F, `display: standalone` | `<link rel="manifest" href="/manifest.webmanifest">` |
| `src/ios-source.svg`, `src/android-source.svg`, `src/maskable-1000.svg` | the exact SVGs the PNGs were rasterised from (1000×1000) | edit here or in the logo system |
| `app-icons-preview.png` | iOS 180, Android 192, maskable 512 (safe circle drawn), Windows 150 and wide, PWA 192 on dark and light grounds | verification sheet, regenerated by the script |

## Head block (everything together)

```html
<link rel="icon" href="/favicon.ico" sizes="48x48">
<link rel="icon" href="/favicon.svg" type="image/svg+xml">
<link rel="apple-touch-icon" sizes="180x180" href="/ios-icon-180.png">
<link rel="apple-touch-icon" sizes="167x167" href="/ios-icon-167.png">
<link rel="apple-touch-icon" sizes="152x152" href="/ios-icon-152.png">
<link rel="apple-touch-icon" sizes="120x120" href="/ios-icon-120.png">
<link rel="mask-icon" href="/safari-pinned-tab.svg" color="#0D0D0F">
<link rel="manifest" href="/manifest.webmanifest">
<meta name="msapplication-config" content="/browserconfig.xml">
<meta name="msapplication-TileColor" content="#0D0D0F">
<meta name="theme-color" content="#F5F0E7" media="(prefers-color-scheme: light)">
<meta name="theme-color" content="#0D0D0F" media="(prefers-color-scheme: dark)">
```
