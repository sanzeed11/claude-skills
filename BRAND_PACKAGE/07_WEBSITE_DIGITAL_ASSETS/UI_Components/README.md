# UI_Components — the website component library

The design system sanzeed.com is built from. `brand.css` (tokens, type, base components) + `components.css` (everything the site needs). `ui-kit.html` is one long page of labelled specimens showing every component in every state, with the real copy and the real images; `tokens-reference.html` prints every token.

## Accessibility

Focus rings (`:focus-visible`, gold, 2 px + 3 px offset) on every interactive element; `.skip-link`; labels on every form control; `aria-current`, `aria-pressed`, `aria-selected`, `aria-expanded`, `role="status"/"alert"` where relevant; 44 px tap targets; colour pairs from `03_COLOUR_SYSTEM/Colour_Reference.md` (gold text on light is Gold Ink `--accent-text`, never Old Gold); `prefers-reduced-motion` honoured globally.

## Using it on the site

```html
<link rel="stylesheet" href="/css/brand.css">
<link rel="stylesheet" href="/css/components.css">
```
Copy `brand.css` with its relative imports (`03_COLOUR_SYSTEM/colour-variables.css` and the woff2 files from `04_TYPOGRAPHY/Font_Files`) or inline the colour variables and point the `@font-face` rules at `/fonts/`. Remove the `.kit-*` / `.spec*` rules at the end of `components.css` for production.
