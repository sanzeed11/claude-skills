# 03_COLOUR_SYSTEM — dark is the gallery, cream is the label

The colour system of the Sanzeed identity: 25 colours in three groups (core dark, core light, accent + functional),
two themes, five gradients, the approved contrast pairs, print specifications — as tokens for code and as a designed
12-page Colour Palette document.

## Files

| File | Format · spec | Use / how to edit |
|---|---|---|
| `Colour_Palette.pdf` | PDF · 12 pages · A4 210 × 297 mm · ≈ 4 MB · fonts embedded | cover · core dark palette · core light palette · accent and functional · hierarchy and proportions (the 70 / 25 / 5 bar, seven rules) · dark theme with UI examples and token table · light theme · gradients · approved combinations with WCAG ratios · print specifications (rich black, gold process / spot / foil, stock) · accessibility and six misuse tiles · back cover. ## Regenerating the Colour Palette document

```bash
cd 03_COLOUR_SYSTEM/src && python3 build_colour_palette.py
node ../../15_SOURCE_FILES/Project_Files/brand-kit/render.js --in Colour_Palette.html --out ../Colour_Palette.pdf --pdf --size 210x297
```

To change a colour: edit the palette in the colour builder, re-run it (regenerates `colour-tokens.json`,
`colour-variables.css`, `Colour_Reference.md` and the swatches), then re-run the two commands above.
The page model and running footer come from `15_SOURCE_FILES/Project_Files/brand-kit/doc.css`.

## Caveats carried into the document

CMYK values are process conversions from sRGB and must be proofed with the printer. Pantone references are nearest
matches by colour distance against published sRGB approximations, not a Pantone library — verify against a physical
swatch book before specifying a spot colour (Old Gold → 7510 C, ΔE 5.4; metallic alternative 871 C / 872 C).
