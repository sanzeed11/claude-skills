26.2 · Formats supplied and not supplied

Open formats, honestly stated.

Every export has an editable source beside it; a PNG without its source is a defect.

FormatWhereNotes

DOCX · PPTXletterheads, invoices, quotations, proposal, official document, decks, social templatesnamed styles; fonts to install from 04_TYPOGRAPHY
HTML · CSS · JSevery layout source, the UI kit, the site, motion sourcesrender with the kit’s render.js
Lottie JSONlogo reveal, loaderimports into After Effects / LottieFiles
MP4 · WebM · MOV · GIFmotion exportsH.264 · VP9 (alpha) · ProRes 4444 (alpha) · GIF ≤ 960 px
TTF · woff2 · JSON · CSS · SCSS · JSfonts and tokensSIL OFL 1.1; tokens for code
Not supplied: .ai, .psd, .indd, .aep, .fig, Canva. These proprietary formats can only be written by their own applications, and no file in this package has been renamed to fake them. Every SVG and PDF opens as fully editable vector artwork in Illustrator and Figma (File → Open; save as .ai from there if the native format is needed). The HTML/CSS, DOCX and PPTX files are the editable layouts; Lottie JSON and HTML/CSS are the motion sources and import into After Effects; the ProRes masters cut into Premiere, Resolve and Final Cut.
Office fonts. Word and PowerPoint cannot drive Fraunces’ optical-size axis; templates name the static Fraunces Light instance. Install the TTFs from 04_TYPOGRAPHY/Font_Files on every machine that edits them.
Imagery. All project imagery is the client’s own at web resolution (960–1600 px). Large-format print items that use it are flagged in their READMEs; supply originals ≥ 2000 px and re-run the build scripts for litho.
26.3 · Naming and production specifications

Named so they can be found.

The naming convention and the digital and print standards every export was measured against (brand kit §7–9).

Naming
sanzeed-<deliverable>--<variant>[-<size>].<ext>

sanzeed-primary-wordmark--full-colour-dark.svg
sanzeed-og--work--ram-katha-show-1200x630.png
sanzeed-poster--campaign-a2-print-ready-cmyk.pdf
sanzeed-lower-third--name--alpha-1920x1080.mov

Lowercase, hyphens; two hyphens before the variant; pixels or scale in the name (-1-10 = 1:10); --dark / --light name the ground the file is drawn for; --print-cmyk / -print-ready-cmyk carry marks and CMYK; --poster is a video’s hold frame; --guide renders are references, never uploaded.

DigitalSpecification
Social and web PNG2× (2160×2160 for a 1080 post) or the platform’s exact pixels; PNG upload, JPG q90 where a platform caps size
Share images1200×630 (centre 1200×600 safe) and 1200×1200
Emailheader 600×200 @2×, masthead 600×150 @2×, signature logo 320×100 @2×

Video1920×1080 / 1080×1920 / 1080×1080 · H.264 CRF 20 · VP9 · ProRes 4444 alpha · 30 fps · Rec. 709 · GIF ≤ 960 px
WebWebP beside PNG for anything on the site; SVG for icons; woff2 subsets; tap targets ≥ 44 px; contrast per Colour_Reference.md

ColourCMYK via print_pdf.py --cmyk; 100 K type, rich black C60 M40 Y40 K100 for solids; Old Gold C0 M27 Y68 K28 or Pantone 7510 C (verify); metallic 871 C / 872 C or foil

Bleed and marks3 mm bleed; crop marks, TrimBox / BleedBox; fonts outlined or embedded
SizesCard 89×51 · A4 / US Letter · DL / C5 · A6 · CR80 · A5 pad · A4 folder 5 mm spine · A5 flyer · A4 trifold (99/98/100) · A2 / A3 posters · stamps 40 mm / 58×22 · signage at 1:10

26.4 · Regenerating from the sources

Edit the master, re-run, export.

Sources sit beside their exports; 15_SOURCE_FILES/Editable_Assets/INDEX.md lists all of them and Original_Designs/INDEX.md the masters. Never retouch an export by hand.

To change…EditThen run

Requirements (all present in the production container): Python 3 with fontTools, cairosvg, Pillow, numpy, pypdf, reportlab, python-docx, python-pptx; Node 22 with Playwright (Chromium); Inkscape 1.2+; Ghostscript; ffmpeg; cwebp; LibreOffice; poppler (pdftoppm, pdffonts). Exported files need nothing. The brand fonts must be installed system-wide so Chromium, Inkscape and LibreOffice render Fraunces as the light serif.
