# Signature mark

The hand-lettered "Sanzeed." signature, vectorised from the original raster artwork (`00_ORIGINAL_ASSETS_BACKUP/logo/signature-dark.png`, 1694×698 px) with potrace at 300 dpi after 3× supersampling. The outlines are editable Béziers; the group `#signature` carries the potrace transform, so scale the group rather than the path.

| Colour | Use |
|---|---|
| `ink` (#1A1816) | Letters, thank-you cards, certificates on Plaster/Paper |
| `white` (#F5F5F7) | On dark backgrounds (website case-study sign-off, video end card) |
| `gold` (#B8863B) | Foil or spot-gold print on light stock |
| `gold-light` (#E9B25A) | Gold on dark backgrounds |
| `black` (#000000) | Single-colour print |

Rules: the signature is the *personal* layer of the identity — it never replaces the wordmark in institutional contexts (invoices, proposals, signage). Minimum width 32 mm in print / 160 px on screen. Keep the flourish underline; never recolour parts of it.
