# Refined original wordmark — two proposals

Your original sanzeed.com wordmark, cleaned rather than redrawn: S, A, N and D are your original shapes re-traced with smooth edges and straight lines made exactly straight; the E bars are exact rectangles at your original sizes; the gold points are at their original positions and size. Only the Z is new.

| Proposal | File stem | Z |
|---|---|---|
| 1 | `sanzeed-wordmark--refined-swoop` | Straight top and bottom bars; the diagonal swoops like the N's right leg |
| 2 | `sanzeed-wordmark--refined-swoop-ring` | Same Z, plus a gold point at the D-dot height, separated from the stroke by a thin ring |

Each proposal is supplied in four colourways — `full-colour-dark` (for dark backgrounds), `full-colour-light` (for light backgrounds), `black`, `white` — as SVG (editable, one path per letter with ids `wm-S` … `wm-D`, points as circles), PDF and EPS (vector, Inkscape), and transparent PNG at 3000 px wide.

The SVGs keep the original `viewBox="0 0 3729 561"` and the `wm-letters` / `wm-dot` class names, so they are drop-in replacements for the wordmark on sanzeed.com.

These are proposals for approval; the rest of the brand package still uses the earlier redrawn logo until one of these is chosen.
