# 06_PHOTOGRAPHY_ART_DIRECTION — photography and art direction system

The imagery layer of the Sanzeed brand: thirty approved project images with a repeatable grade, the portrait in four ratios, an A3 moodboard, a sixteen-page A4 photography guideline, and a set of image-treatment templates (HTML, Python, SVG). Everything is built from the client's own project visuals in `00_ORIGINAL_ASSETS_BACKUP/images/` — no stock, no AI imagery. Every export has an editable source next to it, and every render was checked by eye (logo pairing, clear space, one gold accent, Fraunces 300 display, nothing clipped, tabular figures in tables).

Folder total: ~74 MB, 145 files.

## The idea in one line

**The lit room.** One dominant light source, blacks that hold detail (Night `#0D0D0F`, never crushed), highlights that lean toward Lamp Gold `#E9B25A`, a person for scale walking into the light. Dark is the gallery; the wall label (Title · Place) captions every picture.

**Categories:** museum (14) · projection (11) · event (1) · architecture (4). Named proof projects covered: Prime Minister Museum, Ram Katha Show, Buddha Park, Yuge Yugeen Bharat Museum, India Pavilion Expo 2025 (concept), G20 Tree Show, Tribal Museum, RBI Museum, Army Museum Abu Dhabi.

**The grade** (`grade.py`): sine S-curve contrast 0.18 → additive toe landing black on Night (13 · 13 · 15, fades out by input 22 %) → warm shift of the highlight band (55–100 % luminance) toward Lamp Gold, max 10 % → saturation 1.00. Reference curve 0→13, 16→21, 32→30, 64→57, 128→128, 192→199, 224→229, 255→255.

**Rights note (every image):** employee work — rights remain with the commissioning studio (Tagbin, Sociopixel, DWS, B2W); portfolio and credential use. The portrait is the client's own.

**Known limitation:** the source gallery images are 960×540 (case images 1600×900) and the portrait is 1100×1574. They are web-resolution; the portrait crops are resampled ×1.3–1.8 to reach a 2000 px long edge and are soft at print sizes above A5. For print, request the original camera files / renders and run the same `grade.py` on them.

### `treat_image.py` (Pillow) — crop, grade, veil, label, frame from the command line

```bash
cd Image_Templates
python3 treat_image.py ../Approved_Images/JPG/sanzeed-img-ram-katha-show--projection.jpg out.jpg \
    --ratio 4:5 --focal 0.5,0.45 --width 2160 --veil 0.72 --title "Ram Katha Show" --place "Ayodhya" --counter 015
python3 treat_image.py in.jpg out.png --ratio 16:9 --frame --headline "Eight rooms, lit." --title "…" --place "…"
python3 treat_image.py render.jpg out.jpg --ratio 1:1 --concept --title "Tree Concept" --place "Unbuilt"
```

| Option | Meaning |
|---|---|
| `--ratio 16:9 / 4:5 / 1:1 / 9:16 / 3:2 / WxH` | crop ratio; largest crop centred on the focal point and clamped to the frame |
| `--focal x,y` | focal point as fractions of width and height (from `approved.json`) |
| `--width N` | output width in px |
| `--grade S` | grade strength (default 1.0; 0 = off) — imports `Approved_Images/grade.py` |
| `--veil S` / `--veil-top` | bottom (or top) veil to black, strength 0–1 (brand default 0.72) |
| `--title`, `--place`, `--counter` | the wall label: Inter Tight 600 · Inter 400 · Inter Tight 500 gold |
| `--headline "…"` | Fraunces 300 line; the last word is set in Lamp Gold |
| `--concept` | adds the "CONCEPT VISUALISATION" eyebrow for unbuilt work and AI concepts |
| `--frame` | wraps the result in the room frame (Night canvas, hairline, radius) |
| `--label-scale`, `--quality` | label size relative to the long edge; JPEG quality (PNG/WebP by extension) |

Text is set with the brand variable TTFs in `04_TYPOGRAPHY/Font_Files` (Pillow ≥ 10 with FreeType variable-font support; raqm is present in this container). Importable: `from treat_image import treat, crop_to_ratio, add_veil, add_label, add_frame`.

### `SVG_Frames/` — for Illustrator / Figma / Affinity

`sanzeed-frame--16x9.svg` (1920×1080), `--4x5` (1080×1350), `--1x1` (1080×1080), `--9x16` (1080×1920), `--3x2` (3000×2000), `--room-16x9` (the hairline room frame). Each contains, in order: `#background` (Night), group `#IMAGE` clipped by `#image-clip` holding the rect **`#IMAGE_PLACEHOLDER`** (replace it with your photograph, keep the clip), `#veil-gradient`, the `#wall-label` group (`#counter`, `#title` "[Project title]", `#place` "[Place]") and a `GUIDES — delete before export` layer with the safe margin. Fonts: Inter Tight and Inter (install from `04_TYPOGRAPHY/Font_Files`). Preview: `examples/sanzeed-frame--16x9-preview.png` (the 16:9 frame with an approved image dropped in; guides hidden).

## Rebuild everything

```bash
cd 06_PHOTOGRAPHY_ART_DIRECTION
python3 Approved_Images/build_approved.py          # library, index.md, contact sheet
python3 src/moodboard/build_moodboard.py           # Moodboard.pdf + pages
python3 src/guidelines/build_assets.py             # example images for the guideline
python3 src/guidelines/build_guidelines.py         # Photography_Guidelines.pdf + previews
python3 Image_Templates/build_templates.py         # templates, SVG frames, example PNGs
```

Requires: Python 3 with Pillow, numpy, cairosvg; Node with Playwright (the brand kit's `render.js`); `cwebp`; `pdftoppm` (poppler).
