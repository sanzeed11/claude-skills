# 14_PRESENTATION — the brand presentation

The final-delivery reveal deck for the Sanzeed identity: **56 slides, 16:9, 1920 × 1080 px**, in three forms that are built
from one source — a PDF for presenting, a PNG of every slide, and an editable PowerPoint with real text boxes and real
pictures. Everything on the slides is a real deliverable from the other folders of the package (logos from `02`, guideline
sheets from `02/Guidelines`, swatches from `03`, specimen sheets from `04`, diagrams from `05`, moodboard and graded
images from `06`, share images and favicons from `07`, social from `08`, stationery from `09` and `13`, posters and signage
from `10` and `13`, key frames from `11`, screenshots from `00` and `16`, and the live site's original wordmark from `00_ORIGINAL_ASSETS_BACKUP/logo`). Nothing is redrawn or restyled; copy is confirmed
copy from `01_BRAND_STRATEGY` and the package README.

## Regenerating

```bash
cd 14_PRESENTATION/src
python3 build_presentation.py              # HTML → PDF (render.js) → slide PNGs (pdftoppm) → PPTX (python-pptx) → PPTX PDF (soffice)
python3 build_presentation.py --html-only  # just rewrite the HTML
python3 build_presentation.py --no-pptx    # HTML, PDF and PNGs only
```

Every run first empties `Editable_Presentation/assets/` and re-prepares each copy from the current package file, then
rewrites `MANIFEST.md` (so a rebuilt logo, guideline sheet or mockup is always picked up), and regenerates
`src/derived/` (the styled live-site wordmark for the comparison slide). Logo sizes are computed from each SVG's viewBox.

Requirements: Python 3 with Pillow, python-pptx and lxml; Node with Playwright (the kit's `render.js`); poppler (`pdftoppm`);
LibreOffice (`soffice`); the brand fonts installed system-wide (`04_TYPOGRAPHY/Font_Files` — the static *Fraunces Light*,
*Inter Tight SemiBold* and *Inter* instances must be installed for the PPTX export; the deck in this container used the
copies in `09_PRINT_STATIONERY/_build/fonts` and `10_MARKETING_COLLATERAL/_shared/fonts-static`).

**To change copy or layout:** edit the slide functions in `build_presentation.py` (`build_deck()` — one block per slide, in
order, with the section list in `SECTIONS`); every element is placed in a 1920 × 1080 px coordinate system and both renderers
read the same model, so the PDF and the PPTX stay identical. **To swap an image:** point the `P('…')` path at another package
file; the cover crop is computed from the `focal` point. **To edit the PPTX directly:** open it in PowerPoint or Keynote with
the fonts installed; every text is a text box, every picture is a picture, rooms and swatches are shapes. **To edit the HTML
directly:** it is plain absolute-positioned markup on `brand.css`; re-render with
`node ../../15_SOURCE_FILES/Project_Files/brand-kit/render.js --in Brand_Presentation.html --out ../Brand_Presentation.pdf --pdf --size 508x285.75`.

The original-wordmark slide places the Chromium raster of the live-site SVG in both renderers: its traced, unclosed sub-paths are filled differently once converted to PDF vector (the Z's tapered bottom bar came out straight), and the raster matches what the site shows.

Every slide PNG was opened and checked after the original render: logo variant matched to its ground (full-colour-dark on
Gallery Black / Night, full-colour-light on Plaster, the family slide shows each variant on its own correct tile), clear space
kept around every logo, one gold accent per slide (eyebrow, point, lit word, counters — all the same gold), Fraunces renders

Inter Tight SemiBold and Inter in the LibreOffice PDF), no text clipped or overflowing the margins, no empty boxes, no
placeholder copy. Page sizes measured: 1440 × 810 pt (= 1920 × 1080 px) in `Brand_Presentation.pdf`, 960 × 540 pt in the

three font names only) and rendered by LibreOffice page for page against the HTML render.

## Known limitations

- **Fraunces optical size.** The HTML/PDF sets Fraunces at optical size 144 through the variable font; PowerPoint cannot drive
  the axis, so the PPTX uses the static *Fraunces Light* instance at its default optical size — the same compromise as every
  other Office file in the package. Line breaks in the PPTX can therefore differ by a word from the PDF.
- **Grain and glow.** The 7 % grain on dark slides and the glow on the gold point are CSS effects in the HTML/PDF only; the
  PPTX has the lamp texture (a real image from `05_GRAPHIC_ASSETS/Textures`) but no grain and a flat point.
- **Prepared image copies.** To keep the PPTX and the PDF small, raster images are embedded from pre-cropped, downsized copies
  in `Editable_Presentation/assets/` (manifest included) rather than from the originals; logos are the production SVGs in the
  HTML and the production PNGs from `02_LOGO_SYSTEM/PNG` in the PPTX. Source imagery is web resolution (960 × 540 project
  images), as everywhere in the package.
- **Not a Keynote / Google Slides native file.** The PPTX opens in both; fonts must be installed first.
- **Mockups carry their own captions.** The 13_BRAND_MOCKUPS scenes include a small caption strip at the bottom; the
  gallery slides crop it away (bottom 6 %) and add the deck's own wall label; the event-backdrop composite keeps its in-image
  wall label (G20 LED Show · Gujarat) at the top-left as delivered.
- **"Between two points of light"** (slides 04 and 11) is the line already on sanzeed.com and the name of the 05 illustration,
  not a description of the logo; it is kept as confirmed copy. The audit slide's "Wordmark hand-traced, not constructed" is
  the audit finding as recorded in `01_BRAND_STRATEGY/Brand_Audit.md`.
