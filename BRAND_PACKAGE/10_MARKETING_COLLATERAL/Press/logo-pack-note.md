# Logo pack — where the files are

The logo is not duplicated in this folder. Every production file lives in **`BRAND_PACKAGE/02_LOGO_SYSTEM/`** and is generated from one editable master (`15_SOURCE_FILES/Project_Files/logo-builder/refined_master.svg`). The approved logo (20 Nov 2026) is the refined original wordmark, option B: the hand-drawn SANZEED with a hooked S, a swooping N, a new Z whose diagonal swoops like the N and carries a third point of light in a thin ring — three gold points on A, Z and D. Symbol: the refined S with a full stop. Monogram: “SM.”.

| Need | Use |
|---|---|
| Web, apps, editors | `02_LOGO_SYSTEM/SVG/sanzeed-primary-wordmark--full-colour-dark.svg` (on dark) · `--full-colour-light.svg` (on light) |
| Print, office documents | `02_LOGO_SYSTEM/PDF/` and `EPS/` — vector, fonts outlined |
| Transparent bitmaps | `02_LOGO_SYSTEM/PNG/` — width in the file name, e.g. `-3000w.png` |
| Formal lockup (press, stationery, signage) | `sanzeed-horizontal-descriptor--*` |
| Symbol, avatars, favicons | `sanzeed-symbol--*`, `sanzeed-symbol-tile--*`, `02_LOGO_SYSTEM/Favicon/`, `02_LOGO_SYSTEM/Social_Profile/` |
| Single-ink print, engraving | `--black`, `--single-colour-gold`, `sanzeed-wordmark-plain--*` |

Rules in one breath: full-colour-dark on dark, full-colour-light on light, never the reverse; clear space = half the cap height; minimum 120 px / 28 mm wide for the wordmark; nothing added to the letters; the three points stay gold (they take the ink colour only in single-colour versions); the ring around the Z point shows the background through it. Full rules: `02_LOGO_SYSTEM/README.md` and `12_BRAND_GUIDELINES/`. A one-page summary for editors is page 05 of `Media_Kit/sanzeed-media-kit--a4.pdf`.

Headshots for press: `sanzeed-mirza-headshot--1x1-2000.jpg`, `--4x5-2000.jpg`, `--3x4-2000.jpg` in this folder.
